常見問題

小工具顯示要先在 app 內執行腳本，為什麼？

腳本需要的權限（例如網絡或位置）只能在 app 內批准，小工具本身不能顯示權限詢問。請打開 Scriptile，執行該腳本一次，並批准它要求的權限，小工具便可使用。

小工具多久更新一次？

更新時間由 iOS 排程決定，Scriptile 無法指定確實的時間，更新可能有延遲。

腳本存放在哪裡？

腳本是普通 .js 檔案，可在「檔案」app 的 Scriptile 資料夾找到；如果你開啟 iCloud 雲碟，則存放在 iCloud 雲碟，亦可在 Mac 上編輯。

如何收回權限？

打開該腳本的「私隱」頁面，收回你曾批准的權限或網站。位置、通知等系統權限，亦可在 iOS「設定」中更改。

如何在「捷徑」中執行腳本？

在「捷徑」app 加入 Scriptile 的動作，選擇要執行的腳本，需要時傳入資料。腳本可傳回文字、圖片或資料。

FAQ

The widget says to run the script in the app first. Why?

The permissions a script needs (for example network or location) can only be approved inside the app; a widget cannot show a permission prompt. Open Scriptile, run the script once and approve what it asks for, and the widget can use it.

How often do widgets update?

iOS decides the schedule. Scriptile cannot set an exact time, and updates can be delayed.

Where are my scripts stored?

Scripts are plain .js files. You can find them in the Scriptile folder in the Files app, or in iCloud Drive if you turn it on, where you can also edit them on your Mac.

How do I take back a permission?

Open the script's Privacy page and remove the permissions or websites you approved. System permissions such as location and notifications can also be changed in iOS Settings.

How do I run a script from Shortcuts?

In the Shortcuts app, add the Scriptile action, choose the script to run and pass in input if you need to. The script can return text, images or data.
